# Chemistry writing quality

State the question, method and supported answer clearly. Trace quantitative statements to available tables or calculations. Keep chemical identifiers, units, conditions and data sources explicit. Separate measurements, computed descriptors, heuristic estimates and model predictions. Describe accuracy only when validated. Preserve the requested total PDF scope, including references unless explicitly excluded. Approximate length is a guideline allowing small deviations for content and readability; only explicit user or venue limits are strict. If unspecified, use a concise evidence-based length without a fixed page minimum. Include model training details or repeated-run analysis only if that work is part of the method. Never invent results, references or experiments.
