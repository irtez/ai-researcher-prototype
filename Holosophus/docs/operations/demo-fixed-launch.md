# Временная фиксация настроек демо

`CC_DEMO_FIXED_LAUNCH=1` в окружении Claude Code runner принудительно выбирает
конфигурацию `opus`, effort `high` и вычисления `Local`. Значения модели,
уровня рассуждений и режима, присланные UI, игнорируются. Правило действует
для новых HTTP-запусков и доработок в обоих исследовательских профилях.

Согласования, автоматический таймер согласования, профиль, текст задания
и вложения обрабатываются как раньше. Элементы UI и публичный каталог моделей
не меняются. Сохраняются фактически применённые настройки, поэтому после
принятия запуска шапка показывает Opus / high / Local. Отдельное поле
`settings.json.requested_launch` сохраняет исходный выбор формы. Пока включён
флаг, строка настроек в форме доработки показывает этот выбор с обычной
подписью «Продолжение с прежними настройками». Это только отображение:
SDK, снимки итераций и трассы по-прежнему используют фактические параметры.
При отключении флага либо отсутствии исходного выбора у старой сессии
строка показывает фактические настройки. Последующие доработки не заменяют
исходный выбор. Снимок не содержит ключей или параметров подключения модели.
Снимки уже завершённых итераций не переписываются. Параметры текущей сессии
обновляются только при следующем принятом запуске или доработке.

Это настройка HTTP runner Claude Code. Она не изменяет CodeArkt, CLI-запуски
и собственные модели внешних MCP-инструментов. Менеджер, субагенты и генерация
названия используют сохранённую конфигурацию Claude Code.

Чтобы вернуть обычный выбор, удалить `CC_DEMO_FIXED_LAUNCH` либо поставить `0`
и перезапустить runner при отсутствии активных исследований. Новые задания
снова используют выбор UI. Доработки используют фактически сохранённые
настройки соответствующей сессии. Не редактировать результаты или старые
итерации для снятия ограничения.
