# Консольный прототип AI Researcher

Русскоязычный клиент общего сервера исследований. Работает с Claude Code и
совместимыми моделями из `config/models.yaml`, профилями «Компьютерные науки»
и «Химия». Браузерный интерфейс для работы не требуется.

## Подготовка и запуск

Команды выполняются из `Holosophus/`. Нужны Python 3.12+, uv, Docker Compose,
Claude Code и настройки существующих MCP-сервисов. Общая подготовка описана
в [локальном развёртывании](claude-local.md). Для новой установки скопируйте
`.env_example` в `.env`, если собственного файла ещё нет. Ключи моделей
задаются в `.env`, параметры подключения — в `config/models.yaml`.

```bash
uv sync --locked
make executor-image
make console-services
```

`console-services` запускает отдельный Compose-проект `ai-researcher-console`:
API файлов и сессий, Academia, MLE Kit, Writer Tools, PaperBanana и химические
сервисы. Рабочие файлы находятся в `workdir/` этой копии. Web UI не запускается.
Если порты 5056–5065 заняты прежней локальной установкой, сначала остановите
её соответствующие сервисы. Docker volumes удалять не требуется.

Подсистемы трассировки используют настройки общей установки. При отдельном
развёртывании настройте их по [инструкции трассировки](../observability.md).
Тестирование самого клиента и чтение `--help` не требуют ключей моделей.

В первом терминале запустите сервер исследований:

```bash
make console-runner
```

Во втором терминале запустите клиент:

```bash
make prototype-console
```

Runner слушает `127.0.0.1:5061`, API данных — `127.0.0.1:5065`.
Для другого размещения укажите `--runner-url` и `--data-url` либо переменные
`CONSOLE_RUNNER_URL` и `CONSOLE_DATA_URL`. Запуск через Make принимает
аргументы в `ARGS`, например:

```bash
make prototype-console ARGS='--prompt-file examples/console-smoke/task.txt'
```

Параметр `CC_DEMO_FIXED_LAUNCH` продолжает действовать на сервере. Если он
равен `1`, фактически выполняются Opus / high / Local. Для проверки выбранной
модели, включая DeepSeek, установите `CC_DEMO_FIXED_LAUNCH=0` в окружении
именно тестового runner. Консоль показывает фактические параметры выполнения.
Изменение этого параметра в копии не меняет настройки других установок.

## Работа

Выберите настройки по номерам. Enter оставляет значение по умолчанию.
Вводите задание несколькими строками, отдельная строка `/send` завершает ввод.
Команда `/file путь` читает задание или замечание из файла UTF-8.

Вложения задаются локальными путями, по одному на строку. Пути с пробелами
принимаются целиком. `/remove N` удаляет позицию из списка, Enter завершает
подготовку вложений. Разрешены CSV, XLS/XLSX, DOCX, JSON/JSONL, PNG/JPEG и PDF,
до 20 Мбайт на файл. Имена вложений одной отправки должны различаться.
Исследование начинается после подтверждения и успешной загрузки файлов.

Лента показывает сообщения менеджера и специалистов, краткие сведения об
инструментах и ошибки. Полная история сохраняется сервером. При запросе
согласования выводится документ: `1` подтверждает его, `2` позволяет отправить
замечание, `3` останавливает исследование. Ответ относится к показанной версии
документа. После исправления предлагается новый запрос. В обычном вопросе
менеджера введите текст и закончите его строкой `/send`.

Если включён таймер, его срок отображается рядом с запросом. Закрытый или
заменённый запрос отменяет ввод ответа к прежнему документу. Сообщения агентов
при обычном ожидании не стирают набираемую команду.

| Команда | Действие |
|---|---|
| `/pause` | Запросить паузу |
| `/resume` | Продолжить после паузы |
| `/steer текст` | Передать уточнение после текущего шага |
| `/stop` | Остановить с сохранением по механизму управляющего сервера |
| `/cancel` | Немедленно остановить исследование |
| `/exit` | Отключить клиент, продолжив исследование на сервере |
| `/help` | Показать подсказку |

После завершения доступно меню доработки, файлов, новой задачи и выхода.
Доработка сохраняет сессию, позволяет добавить новые файлы и изменить настройки
согласований. Результат предыдущей итерации остаётся в серверной истории.
Выбранный файл скачивается в `console-downloads/<session_id>/` с сохранением
относительного пути. Существующий файл не перезаписывается.

## Повторное подключение

Идентификатор сессии печатается при запуске. Для повторного входа:

```bash
make prototype-console ARGS='--session research_идентификатор'
make prototype-console ARGS='--list'
```

Также доступен пункт «Мои сессии». Клиент повторно читает серверную историю,
поэтому при новом подключении сообщения текущей итерации показываются сначала.
Внутри одного подключения повторные опросы не дублируют сообщения.

Каталог `.console-state/` содержит постоянный идентификатор владельца. Сохраняйте
его между запусками. Для отдельного пользователя предусмотрен `--state-dir`.
При включённой серверной авторизации задайте Bearer-токен в переменной
`AI_RESEARCHER_CONSOLE_TOKEN` и передайте `--client-id` с именем пользователя,
которому выдан токен. Это имя должно совпадать с владельцем сессии на сервере.
Без явного имени клиент с токеном не запускается, чтобы разные API не
обращались к разным каталогам сессий. Например, после задания токена в окружении:

```bash
make prototype-console ARGS='--client-id alice --list'
```

Токен не сохраняется клиентом. Ключ выбранной языковой модели клиенту не нужен.

Разрыв связи не считается завершением исследования: консоль повторяет чтение
состояния, а сервер продолжает работу. При неоднозначном ответе на запуск
клиент сообщает session_id и не отправляет задание повторно автоматически.

## Проверка

```bash
uv run pytest -q tests/test_console_api.py tests/test_console_monitor.py \
  tests/test_console_app.py tests/test_console_pty.py
make verify
```

Тест PTY запускает настоящий консольный процесс с имитатором HTTP API,
проверяет согласование с замечанием, выход, повторный вход, скачивание и
доработку с вложением. Вызовов LLM при этих проверках нет.

Для небольшого реального прогона предусмотрены `examples/console-smoke/task.txt`,
`compounds.csv` и `feedback.txt`. Выберите DeepSeek, локальные вычисления,
ручное согласование источников и плана. Для проверки корректировки плана
попросите указать единицы молекулярной массы, затем подтвердите исправление.
После результата отправьте текст `feedback.txt` как доработку.

## Границы

Поддерживается только сервер Claude Code. Терминал не содержит встроенного
просмотрщика PDF и изображений: скачанные файлы открываются отдельными
программами. Удалённые вычисления требуют настроенного узла, как в общем ядре.
Команды остановки не заменяют резервное копирование результатов.
Остановка runner завершает его процессы, даже если клиент уже отключён.
